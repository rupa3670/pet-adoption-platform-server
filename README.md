# Pet Adoption Platform (server)

## Purpose

This is the backend/API for the Pet Adoption platform. It handles authentication, pet listing management, and the full adoption request workflow, providing secure REST APIs that the client consumes to power the pet adoption experience.

## Live URL

[https://pet-adoption-platform-client-six.vercel.app/]

## Features

-  **Secure Authentication** 
-  **Pet CRUD APIs**
-  **Search, Filter & Sort APIs**
-  **Adoption Request Management** 
-  **Adoption Control Logic** 
-  **CORS & Environment-Secured** 

## NPM Packages Used

- `express` — server framework
- `mongodb` — database driver
- `better-auth` — authentication & session management
- `cors` — cross-origin resource sharing
- `dotenv` — environment variable management
